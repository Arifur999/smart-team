# Team skills

Skills written for smart-team itself live here, one folder per skill with a `SKILL.md` at its root
(same format as `~/.claude/skills`). The hub prefers a skill from this folder over one with the same
name on the hub PC.

Planned, written in the phase that first uses them: `intake-brief`, `team-review`, `reference-match`,
`video-qa`, `design-reference-match`, `design-qa`, `marketing-strategy`, `copywriting`,
`social-content`, `seo-ads`, `marketing-qa`, `final-qa`.
