# Search and ads

Match what people type to what the client sells, and pay only for intent that converts.

## Keywords

- Start from the product, the customer's words (research) and the competitors.
- Group by intent: transactional (buy, book, price, near me), commercial (best, vs, review), informational.
- For each: keyword, intent, priority (P1 money, P2 support, P3 content), where it came from (Google autocomplete,
  People also ask, a competitor page, Search Console if given). Do not invent search volumes; say "not measured"
  when there is no source.

## Pages

For each target page: title (<= 60 characters, keyword first), meta description (<= 155, a reason to click),
H1, and the one question the page must answer.

## Search ads

Ad groups by tight theme: 15 headlines (<= 30 characters each, count them), 4 descriptions (<= 90), final URL,
sitelinks. Negative keywords list (free, jobs, DIY... as relevant).

## Measure

What to track (conversions, cost per lead), the first two weeks' checks, and when to pause a keyword.
Write everything to `05-search/vN/search-ads.md`.
