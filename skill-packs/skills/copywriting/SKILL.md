# Copywriting

Clear beats clever. Specific beats impressive. True beats everything.

## Rules

- Start from `02-strategy/STRATEGY.md`: each piece serves one key message and one CTA.
- Use the customer's own words from the research. Write to "you".
- Every claim, number or name comes from the research (with its source) or the brief. Nothing invented.
- Brand voice and banned words come from the brand kit skill when loaded (for Naxified: no dashes, no "leverage",
  "seamless", "unlock"...).
- Short sentences. One idea per sentence. Verbs first in CTAs ("Book a call").
- Run the humanizer checks: no filler, no rule-of-three habits, no inflated symbolism.

## Deliver (`03-copy/vN/copy.md`)

For each piece the strategy lists:
- **Headline**: 5 options, the recommended one first with one line on why.
- **Body**: the recommended version, within the channel's length.
- **CTA**: the button or link text.
- **Sources**: the research facts used.

Respect limits: Google ads headline 30 / description 90 characters; meta title 60 / description 155;
Instagram first line under 125 characters before "more".
