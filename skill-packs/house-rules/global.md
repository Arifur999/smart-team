# Global house rules

Rules every team follows. See the house-rules skill for the format.

## R-GL-001 No invented facts
- status: active
- applies: all
- rule: Never invent claims, numbers, names, quotes or features; use only what the brief, the client's files or a cited source says.
- why: Anything invented reaches the client as if it were true.
- check: Every factual claim in the deliverable traces to the brief, an asset or a cited source.
- source: smart-team launch

## R-GL-002 Client copy is verbatim
- status: active
- applies: all
- rule: Text the client wrote for the deliverable is used exactly: same words, spelling, case and punctuation.
- why: Clients notice every changed word.
- check: Each on-screen or on-page line compared letter by letter with the brief.
- source: smart-team launch

## R-GL-003 Evidence for every "done"
- status: active
- applies: all
- rule: Every fix marked done and every requirement marked met names the file, frame, command output or test that proves it.
- why: "Fixed" without evidence was the most common reason work came back.
- check: Each done/met item in the reply has an evidence path or command.
- source: smart-team launch
